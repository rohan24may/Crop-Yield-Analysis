# Crop Yield Analysis & Prediction

A data-driven project to analyze historical crop yields in India and predict crop yield using agricultural and climatic factors.

## Project Objectives

- Analyze historical crop yield patterns across Indian states and seasons.
- Explore relationships between rainfall, fertilizer, pesticide usage, and crop yield.
- Build and evaluate machine learning regression models.
- Develop visualizations and an interactive dashboard.

## Dataset

- **Source:** [Mendeley Data — Crop Yield Dataset](https://data.mendeley.com/datasets/ncw2vbcgnk/2)
- **Geographical focus:** India
- **Data period:** 1997–2020

## Technology Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit (planned)
